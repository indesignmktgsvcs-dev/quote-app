# INDesign Quotes (V127)

Quotation, costing and invoice tool for INDesign Marketing Services.
Works on computer and phone from the same link:

**https://indesignmktgsvcs-dev.github.io/quote-app/**

## Install on phone
- Android (Chrome): open the link → tap the burgundy **📲 Install App** button (or ⋮ menu → Install app).
- iPhone (Safari): open the link → Share → **Add to Home Screen**.

## Update to a new version
Add file → Upload files → drag in the new `index.html` and `service-worker.js` → Commit changes.

Quotes are saved on each device, not on GitHub. Never upload quote files, passwords or bank details here.
